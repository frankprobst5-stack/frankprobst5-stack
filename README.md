## Featured project

### 🏛️ [Stratum CMS](https://github.com/frankprobst5-stack/Stratum)

A modular community platform for clubs and associations — forums, wiki,
articles, calendar, gallery, downloads, real-time chat, dues/donations,
advertising, and a full front-end customization system, all in one
self-hosted PHP/MySQL app with no framework and no build step. Built to
give clubs currently running aging e107, SMF, or Composr installs a real,
modern replacement — same feature set they already rely on, current code
underneath, running on the same cheap shared hosting they already have.

**Status**: actively developed, core feature set shipped, still growing.

**Stack**: PHP 8.2+, MySQL, no framework, no npm/build step by design.

**License**: AGPL v3 — free to run, modify, and self-host; if you host a
modified version as a network service, you share your changes back. Kept
that way on purpose.
