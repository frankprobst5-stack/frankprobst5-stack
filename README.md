### 🏰 [Project Citadel](https://github.com/frankprobst5-stack/Project-Citadel)

A self-hosted, offline-first home command center — media library, secure notes, an offline
AI assistant, an offline encyclopedia, home-school lessons, homestead/emergency logistics
tracking, and real smart-home automation, all running on your own hardware in Docker, with
zero dependency on the internet once it's up. Built for real off-grid and disaster-prone
use, not as a tech demo.

### 📡 [WayStation](https://github.com/frankprobst5-stack/WayStation)

The comms half of the same system — an offline-first amateur radio / emergency-communications
desktop app: net control, ICS-style incident forms, mesh networking, Winlink, JS8Call,
rig/rotator control, and real propagation/space-weather data. Online enriches the picture;
grid-down is the environment it's actually built for, not an afterthought.

**Status**: both are real, working, public releases as of this month — not prototypes.
Citadel ships a one-line installer; WayStation ships real Windows/Linux binaries. Early days
as public software, under active field testing, with real known-gaps documented honestly in
each repo's own `ROADMAP.md` rather than hidden.

**Looking for testers and bug reports** — both repos have real issue templates ready for it.
If you're into off-grid prep, amateur radio, or homesteading, I'd genuinely like to hear what
breaks.

## Also: Stratum CMS

### 🏛️ [Stratum CMS](https://github.com/frankprobst5-stack/Stratum)

A modular community platform for clubs and associations — forums, wiki, articles, calendar,
gallery, downloads, real-time chat, dues/donations, advertising, and a full front-end
customization system, all in one self-hosted PHP/MySQL app with no framework and no build
step. Built to give clubs currently running aging e107, SMF, or Composr installs a real,
modern replacement — same feature set they already rely on, current code underneath, running
on the same cheap shared hosting they already have.

**Status**: actively developed, core feature set shipped, still growing.

**Stack**: PHP 8.2+, MySQL, no framework, no npm/build step by design.

**License**: AGPL v3 — free to run, modify, and self-host; if you host a modified version as
a network service, you share your changes back. Kept that way on purpose.

Genuinely looking for more hands on this one too — PHP backend, front-end/CSS, or just
testing and filing real bugs. Take a look at the repo and open an issue, or reach out
directly.
